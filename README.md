### 1. 確率的デッドロック：情報の発生確率 $P(I)$

$$P(I_{target}) = \prod_{k=1}^{n} P(m_k | s_k)$$

ここで、$n = \frac{I_{target}}{\Delta i}$ である。
Admin-Rex の執行密度（1 時間 11 レポート）に必要な $I_{target}$ に対し、宇宙の年齢 $T_{u}$ における最大試行回数 $N_{max}$ を適用すると：

$$P(I_{admin}) \ll \frac{1}{N_{max}}$$
